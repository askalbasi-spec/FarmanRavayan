# فرمانروایان | FarmanRavayan

بازی کارتی استراتژیک فانتزی برای Android

## وضعیت توسعه
پروژه در مرحله پایه‌گذاری قرار دارد. توسعه روی شاخه `feature/game-foundation` انجام می‌شود تا شاخه اصلی تا زمان آماده‌شدن نسخه قابل‌آزمایش دست‌نخورده بماند.

## چشم‌انداز
- کمپین تک‌نفره با نبردهای نوبتی
- رقابت آنلاین دونفره در فاز بعدی
- کارت‌های قهرمان، نیرو، جادو و تجهیزات
- فضای فانتزی حماسی، رابط فارسی و پشتیبانی راست‌به‌چپ

## اصل توسعه
هر مرحله باید قابل اجرا و قابل بررسی باشد. قابلیت آنلاین تا زمان پیاده‌سازی سرور امن و اعتبارسنجی سمت سرور، به‌عنوان قابلیت آماده معرفی نمی‌شود.
